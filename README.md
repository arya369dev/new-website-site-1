# FORMA — Premium 18-Parameter Website Starter

A complete, responsive, cinematic one-page website implementing the 18 required landing-page parameters. This is a **new-brand demonstration**. FORMA, its services, case studies and visual identity are placeholders until the real business details are provided.

## GitHub upload

1. Create a new GitHub repository.
2. Upload `index.html`, `style.css`, `script.js`, `robots.txt`, and `README.md` to the repository root.
3. Enable GitHub Pages under **Settings → Pages → Deploy from a branch → main → / (root)**.
4. The website can also be deployed on Vercel using the same repository, with framework preset **Other**.

## Before public launch

- Replace FORMA with the actual business name and add approved brand assets.
- Replace concept case studies with real, permissioned work and validated results.
- Add authentic testimonials, verified credentials and any actual pricing.
- Configure an enquiry destination. In `script.js`, change `const recipient=''` to your real email address for a `mailto:` enquiry flow. For reliable delivery, replace this with a server-side endpoint or form service and add spam protection and a privacy policy.
- Update SEO metadata, canonical URL, and structured data after the final domain and business details are known.
- Update `robots.txt` and add a generated `sitemap.xml` after your domain is known.
- Test on real mobile devices, verify accessibility, run Lighthouse, and verify forms before publishing.

## Technical notes

- Pure HTML/CSS/JavaScript, no build step or paid dependencies.
- Responsive, keyboard-friendly, and respects reduced motion.
- Includes basic metadata and semantic content. Advanced SEO/AEO/GEO requires actual business details and domain.
- Google Fonts require an internet connection; fallback fonts are defined.
- This is a polished starter, **not a fully configured production business website**. Email submission is intentionally not represented as successful until delivery is configured.
